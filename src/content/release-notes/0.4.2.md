## Private AI cleanup with Ollama or LM Studio

If you run AI models on your own computer with Ollama or LM Studio, Kusema now
works with them directly. Nothing you say leaves this computer.

- **Pick them by name:** when you set up AI cleanup, or later on the **Post
  Process** page, choose **Ollama (on this computer)** or **LM Studio (on this
  computer)**. They're at the top of the list,
  marked **Private: stays on this computer**. You don't need an API key.
- **Your models, listed for you:** the model list shows the models you have
  installed. If Ollama or LM Studio isn't running, Kusema says so and links to how
  to set it up.
- **Works in Privileged mode,** like everything else on this computer, and every
  request still shows in the privacy ledger.
- **Nothing to redo:** if you had set up the Custom provider to use Ollama or LM
  Studio on this computer, Kusema switches you over and keeps your model. The
  setup assistant now picks Ollama for you when it finds it.

## The recording pill stays see-through

If Windows ran very low on memory, the pill shown while you speak could get a
solid black box around it until you restarted Kusema. Kusema now notices when
this happens and redraws the pill, so it's see-through again by the next time
you speak.

## Kusema in your language

Every part of Kusema is now translated into all 25 languages it offers besides
English, and the app is called Kusema everywhere. Counts like "3 days" now read
correctly in languages with more than one plural form, such as Russian, Polish,
Czech, Ukrainian, Arabic and Hebrew.

The new translations were made by machine. If something reads oddly in your
language, please tell us using **Report a problem or suggest a feature** on the
About page.
