## Automatic updates

Kusema now updates itself. When a new version is out, the footer shows
"Update available"; click it to download and install. You can also check
from the tray menu.

## Also in this version

- **Ask Kusema:** hold the assistant shortcut, ask a question out loud, and
  hear the answer.
- **Natural voices:** download the Kokoro voices on the Assistant page for
  more natural speech, generated on your computer.
- **Safer API keys:** keys for AI providers are stored in Windows Credential
  Manager instead of the settings file.
