## Fixed: Kokoro voices failing to download on new installs

On a new install, downloading Kokoro voices stopped with "server returned
HTTP 404 Not found": the address Kusema downloaded the voice engine from
(ONNX Runtime, Microsoft's open-source engine) started answering "not found".

- **A reliable source.** Kusema now downloads the voice engine from its own
  copy on Hugging Face: just the one file it needs, about 6 MB. If that can't
  be reached, it uses Microsoft's official package on nuget.org instead.
- **Checked before use.** Kusema checks each download is exactly the file it
  expects. If it isn't, the file is deleted and nothing is installed.
- **A clearer message.** If the download fails, Kusema now says "Couldn't
  download the voice engine. Check your connection and try again. Windows
  voices still work in the meantime." Next to it is a **Retry** button. The
  technical detail is in the info icon's tooltip.

The Kokoro download is about 126 MB in total.
